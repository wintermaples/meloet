# 聞いてほしい所（のび縮みと音の高さ）

オーナーさんへ。歌や声のクリップを、曲のテンポに合わせてのばしたり縮めたり、高さを変えたりする部品（Signalsmith Stretch）の音です。
ヘッドホンで聞いてください。声ごとにフォルダが 1 つあります。素材の出どころは `README.md` にあります。

答えてほしい事は、いちばん下の 5 つです。

## ファイルの名前の読みかた

| 名前 | 中身 |
|---|---|
| `original.wav` | もとの声（何もしていない） |
| `stretch-x0.75-…` | 長さを 0.75 倍に（速くなる。テンポを 1.33 倍にしたのと同じ） |
| `stretch-x1.25-…`、`stretch-x1.5-…` | 長さを 1.25 倍、1.5 倍に（ゆっくりになる） |
| `pitch-12-…`、`pitch-3-…`、`pitch+3-…`、`pitch+12-…` | 高さを半音で −12、−3、+3、+12（長さはそのまま） |
| `…-keep-…` | 「声の感じを保つ」オン |
| `…-move-…` | 「声の感じを保つ」オフ（声の感じも高さといっしょに動く） |
| `…-keep200-…` | 「声の感じを保つ」オンで、声のもとの高さを「200 Hz あたり」と部品に教えた物（ふつうは部品が自分でさがす） |
| `both-x1.25+3-keep-…`、`both-x0.8-3-keep-…` | 長さと高さを両方 |
| `ramp-0.8to1.25-…` | だんだん速くなる（はじめは 0.8 倍の速さ、おわりは 1.25 倍の速さ） |
| `…-default` | 部品のはじめの設定（ていねい） |
| `…-cheaper` | 部品の軽い設定（作るのが 1.5 倍ほど速い） |
| `…-short` | 短い区切りの設定（部品の設定ではなく、ためしに足した物。声には短いほうがよい、という話があったので） |

## くらべかた

1. **のび縮み**: `original.wav` → `stretch-x1.25-default.wav` → `stretch-x1.5-default.wav`、そして `stretch-x0.75-default.wav`。
   - 声が**こもる**、水の中のように**ゆれる**、**金属っぽい**ひびきがつく、**二重に**聞こえる（声が 2 人いるよう）、がないか。
   - 言葉のはじめ（「た」「か」「ぱ」のような音）や歌いだしが**にじむ**、ぼやける、2 回鳴る、がないか。
   - 息の音やサ行が、シュワシュワした別の音にならないか。
2. **設定のちがい**: 同じ倍率で `-default`、`-cheaper`、`-short` をくらべる。どれがいちばん自然か。ちがいがわからなければ、それも答えです。
3. **高さ**: `pitch+3-keep-default.wav` と `pitch+3-move-default.wav`、`pitch-3-keep-…` と `pitch-3-move-…`。
   - `move` は、上げると子どもや小人のような声、下げると大きな人のような声になります。`keep` は、同じ人が高く（低く）歌ったように聞こえるはずです。そう聞こえるか。
   - `keep` のほうに、こもり、ゆれ、ザラザラがふえていないか。
   - 高さが**正しいか**（+3 が、ちゃんと半音 3 つ上に聞こえるか。少しずれて聞こえないか）。この部品は、高さを変えたときに数セントずれる事があるのを、数で見つけています。
4. **大きく変える**: `pitch+12-…` と `pitch-12-…`（1 オクターブ）。`keep` と `move` のどちらが使えそうか。どちらもだめなら、だめと。
5. **`keep` と `keep200`**: ちがいが聞こえるか。どちらがよいか。
6. **両方**: `both-…`。のび縮みだけ ・ 高さだけのときより、悪くなっていないか。
7. **だんだん**: `ramp-0.8to1.25-default.wav`。速さがなめらかに変わるか。とちゅうで音がとぶ、ゆれる、がないか。

## 答えてほしい事

1. のび縮みは、**何倍から何倍まで**なら使えそうですか（0.75 ・ 1.25 ・ 1.5 のうち、どこまで）。
2. 高さは、**半音いくつまで**なら使えそうですか（±3、±12）。
3. 「声の感じを保つ」は、**はじめからオン**でよさそうですか。オンのほうが悪く聞こえる所はありましたか。
4. 設定は `default` ・ `cheaper` ・ `short` の**どれ**がよいですか。
5. 話し声と歌声、男の声と女の声で、**とくに悪い組み合わせ**はありましたか。

古い録音（1950〜60 年代のテープ）の素材は、もとから雑音があります。`original.wav` とくらべて、ふえた分だけを聞いてください。
