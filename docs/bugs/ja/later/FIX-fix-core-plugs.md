# fix-core-plugs — 直す途中で見つけたが、直していない点

- crates/meloet-core/src/service.rs:3576-3595 — AI からの put で `SetState` が拒まれても、その後に `Hosts::state` を送ります。`Hosts` はそのときプラグインが言った内容を覚えます(状態の一部を取り込んでいるかもしれません)。`put_song_state_back` は、`Ready` のプラグインにだけ曲の状態を戻すため、その時点で `Ready` でないプラグインは、後の読み直しのために中途半端な状態を保持し続けます。
- crates/meloet-core/src/service.rs:2588-2597 と play/plugs.rs の `load_again_at` — エンジンが作り直されるとき、`Reloading` 中のプラグインがあると、失われたエンジンは止まったスロットを返します。`unload_gone` がチケットを `ids` から取り除き、`Hosts` のスロットをアンロードするかもしれません。それは、再読み込みが途中か、答えた直後の時点です。すると、再読み込みされたプラグインは、`Hosts` が手放したスロットを持って新しいエンジンに入ります。読むだけで、再現はしていません。
- play/plugs.rs の `reload_plugin` と `place_waiting` — 「入れかえる」の試聴中に、席のプラグイン自身が失敗し、同じ試聴の間に「もう一度読みこむ」を押したものの、そのプラグインがこの PC から消えている場合、その席にはプラグインがなくなります。Esc を押すと、席には、サイン波の代わりではなく、無音の代わりが戻ります。
