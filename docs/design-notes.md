第 3 版の 3 章の文から帯の決まりを組み、窓の高さを 1px ずつ動かして、表と突きあわせました（100 % の px）。**表の 5 行 × 5 列は、すべて合いました。**

|---|---|---|---|---|---|

### 34 自動でひらきなおす高さで、ほかの帯が 1px で大きくへる

**いつまでにほしいか**: 第 3 版の帯の決まりを作る前（次の仕事）。

**何が困るか**
- 自動でたたまれた帯は、入るようになった高さで、ひらきなおります。そのとき、のびていた帯が、いちばん小さい高さまで一気にへります。
- 仕様書の「この順なら、窓を高くして何かがへることも、消えることもない」は、帯の組が変わらないあいだは本当です。けれど、ひらきなおす高さでは、窓を 1px 高くすると、ほかがへります。

**本物で測った数字**（帯の決まりの写しで、窓の高さを 1px ずつ動かして確かめた。100 % の px）

| ひらいている帯（あと＝新しい） | 高さ | 1px 高くしたときに起きる事 |
|---|---|---|
| ミキサー、ピアノロール | 943 → 944 | ミキサーがひらきなおし、ピアノロールが 736 → 268（ノート 49 行 → 10 行）、アレンジが 87 → 40 |
| ピアノロール、ミキサー | 943 → 944 | ピアノロールがひらきなおし、ミキサーが 660 → 516、アレンジが 163 → 40（トラックの行 → 全体図） |
| 取り消しの履歴、ピアノロール | 675 → 676 | 履歴がひらきなおし、ピアノロールが 515 → 268 |
| ピアノロール、取り消しの履歴 | 675 → 676 | ピアノロールがひらきなおし、アレンジが 307 → 40（トラックの行 → 全体図） |
| ミキサー、取り消しの履歴 | 923 → 924 | ミキサーがひらきなおし、アレンジが 555 → 40（トラックの行 → 全体図） |
| 取り消しの履歴、ミキサー | 923 → 924 | 履歴がひらきなおし、ミキサーが 660 → 516、アレンジが 143 → 40（トラックの行 → 全体図） |

- 高い窓（1200）でミキサーとピアノロールの順にひらき、900 に低くして、944 にもどすと、上の 1 行目と同じ事が起きるのも確かめました。

**作る側からの案**
- **案 A**: 仕様書のまま（自動でひらきなおす）。
  - あきらめる物: ひらきなおす高さで、上の表の段差が出る。
- **案 B**: 自動でひらきなおさない。たたまれた帯は、帯札でひらきなおす。
  - 窓を高くしても帯の組が変わらないので、へる所はなくなります（決まりから言える事。動かしてはいません）。
  - あきらめる物: 窓を低くして、また高くもどしたとき、自分で帯札を押してひらきなおす。

### 35 自動でひらきなおすときの順番と、「2 つまで」の決まり

**いつまでにほしいか**: 34 と同じ。

**何が困るか**（仕様書にない所）
- ひらきなおした帯は、ひらいた順で古いままか、新しい帯として数えるか。残りの高さを先にもらう帯が変わります。手元の確かめでは、古いままとして数えました。
- 自動でたたまれた帯を待っているあいだに、人が別の帯をひらくと、「2 つまで」の決まりで、待っていた帯はひらきなおせません。
  - 確かめた例: 1200 でミキサー、ピアノロールの順にひらきます。900 に低くすると、ミキサーが自動でたたまれます。そこで取り消しの履歴をひらくと、ピアノロールと履歴の 2 つになります。そのあと 1600 にしても、ミキサーはひらきなおしません。
  - このとき、待っていた帯（ミキサー）を、人がたたんだのと同じ扱いにするか。

**作る側からの案**: 人が帯をひらいたり、たたんだりしたら、待っていた帯は、人がたたんだのと同じ扱いにする（ひらきなおさない）。
- あきらめる物: 待っていた帯がもどってこない。
