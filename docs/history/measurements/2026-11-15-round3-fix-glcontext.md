- 版: `4f056da` の上の作業ツリー（この直し）。release、`target/r3-fix/release/meloet`。
- PC: **静かではない**。別の係が別の作業ツリーで Rust をビルドしていた（load average 1.0〜6.2）。ヤチヨさんの meloet は動いていない（`ps -u wintermaples`）。RTX 5060 Ti、WebKitGTK 2.52.6、バッファ 256、48000 Hz。鍵 → 画面の数は、棟梁が静かな PC で取りなおす。
- 測りかた: `tools/measure/latency.sh --no-build --window W×H --state recording --pattern mixed --piano-roll`（1280×800 で 3 回、1920×1080 で 1 回）と、`tools/measure/ui-script.sh --no-build --script pr-drag:100`（1920×1080、ノート 1 万の曲）。
- 足した見はり: `frame-profile.json` のコマに `made`（そのコマで作った文脈ごとに、区画、`getContext` の時間 `contextMs`、シェーダーのコンパイルとリンクとバッファ `programMs`、最初の描画 `firstDrawMs`）。
- 生の数: `target/r3-fix/m/{before-1,after-1280-1..3,after-1920-rec,after-drag}/`。

## a. 200 ms は何か

直す前（区画は slot が初めて入ったときに文脈を作る）の 1280×800 録音中、1 回:

| コマ | measureMs | 作った文脈: getContext / シェーダー / 最初の描画（ms） |
|---|---|---|
| ページを読んだ直後 | 866 | masterMeter 50 / 1 / 0、inputKeys 202 / 1 / 1、inputVelocity 202 / 0 / 0、trackMeters 202 / 1 / 0、arrangeLanes 202 / 1 / 0 |
| 録音中の最初のノート（`pianoRollLive`） | 54 | pianoRollLive 52 / 1 / 0 |

- わかった事（確かさ A: この PC で測った数）: 止まっているのは `canvas.getContext("webgl2")` の中だけ。1 回 **50 ms か 200 ms**（どの回も 50 前後か 200 前後のどちらか。間の値は出ない）。シェーダーのコンパイルとリンクは 1 ms、最初の描画は 1 ms 以下、canvas を入れたあとのレイアウトは measureMs の残り（1〜2 ms）。
- 50 と 200 の 2 つの値しか出ないので、計算ではなく、WebKit か EGL の中で何かを待っている形（確かさ C）。なぜかは調べていない。
- 前に使った canvas を池から取りなおす時は、文脈を作らないので速い（ドラッグの 2 回目からが軽いのはこのため）。

## b. 直しかた

- 区画は、slot が初めて入ったときではなく、`use:glRegion` の箱が来たとき（起動、帯をひらいたとき）に canvas を取り、箱があるうちは slot がなくても持つ（大きさ 0×0、描かない）。箱が去ると池に返す（`ui/src/gl/engine.ts`、`ui/src/gl/slot.ts`）。
- のびる物の区画の箱は、使っていない間もおく:
  - `recordingClip`: アレンジのレーンいっぱいの `.rec-host`（中の `.rec-tail` が slot。録っている間だけ）。
  - `pianoRollLive`: 前からノートの場所いっぱいの `.live-host`（中の `.live-box` が slot。ドラッグ中と録音中だけ）。
- 数: どちらも前から `docs/architecture.md` 7 章の表で 1 と数えていたので、最大（11）は変わらない。テストは `ui/tests/arrange.gl.test.ts`（場面ごとの文脈の数。`takes` と `takesArrange`、`tracks16` で、これまで 0 だった `pianoRollLive`・`recordingClip` が 1 になる）と、`ui/tests/gl.surface.test.ts`（「区画の箱が来たときに文脈を作り…」: slot を 3 回出し入れしても作った数は 1、箱が去ると次の区画が同じ canvas を使う）。
- 代わりに、帯をひらくコマが、作る文脈の数だけ重くなる（下の表）。どちらも人がクリックした瞬間で、鍵を弾いている途中ではない。
