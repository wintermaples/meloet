## 3. 15-C を 260 回

`python3 -I tools/measure/window-rounds.py visits --rounds 260 --seed 7`。Surge XT の窓をひらいたまま、次の 5 つを乱数でまぜた。

- 変える訪問（122 回）: 窓にキーボードをわたす → 窓の中に作り物のドラッグ（ポリフォニーの数、シーンのモード、次のパッチ、前のパッチ。3 割は 2 か所）→ キーボードを外す。
- 何もしない訪問（30 回）、取り消し（60 回）、やりなおし（21 回）。
- 訪問の途中で、右の欄から値を決める（27 回。`SetPluginParam`、`commit: true`）。「その時までの窓の分を 1 手、欄の 1 手」になるはず。

1 つごとに、`undoCount` ・ `redoCount` と、**プラグイン自身の状態**（曲を保存して、ファイルの中の Surge XT のバイトを読む。保存は手にならない）を、道具の持つ履歴のひな形とくらべた。

| | 回 | 手の数が合わない | 状態が合わない |
|---|---|---|---|
| 変える訪問 | 122（うち 111 回は本当に変わった） | 0 | 0 |
| 何もしない訪問 | 30 | 0 | 0 |
| 取り消し | 60 | 0 | 1（下） |
| やりなおし | 21 | 0 | 0 |

- **手の数は 260 回とも合った**（最後は取り消し 111 ・ やりなおし 0）。変わらなかった訪問は手にならず、変わった訪問は 1 手、訪問の途中の欄は別の 1 手。
- **取り消し ・ やりなおしのあと、プラグインの状態は 81 回のうち 80 回、バイトまで同じに戻った**。合わなかった 1 回（別の種の 40 回でも 1 回）は、Surge XT が状態を読みなおしたあと、同じパッチ（「Tubular」「Clarinet」）で `deform_type="0"` という属性を 2 つ余分に書いた物（16〜32 バイト長い）。Surge XT 自身が、あるパッチでは状態を書いて読んでも同じバイトにならない。meloet の戻し方の話ではないと見ている。音の出る値は同じ。
- 落ちなかった（終わりの値 0）。終わりのメモリ: meloet 397.9 MB、WebKitWebProcess 356.9 MB、Surge XT の plughost 118.7 MB（パッチを何十も読んだあと）。195 秒。
- **音でも確かめた**（1 回、出口を録った。C4 を 200 ms ごと）: はじめ −32.6 dBFS ・ 上向きのゼロ交差 237 / 秒 → 次のパッチにする訪問 −32.1 ・ 230 → 取り消し −32.6 ・ 237 → やりなおし −32.1 ・ 230 → もう 1 つ次のパッチ −32.1 ・ 239 → 取り消し −32.1 ・ 231 → 取り消し −32.6 ・ 236 → やりなおし −32.1 ・ 230 → やりなおし −32.1 ・ 238。どの段も、その手の音に戻った。

- **30 Hz は動いている**（ミキサーのメーターを描くコマは半分）。30 Hz の区画が四角の数を増やしてはいない（変わった四角は、16 本でも 10 本でも 5〜6 個が主）。

- 16 本のミキサーは、1920 px の窓にストリップ 16 ＋ 戻り 2 ＋ マスターが全部は入らない（横に送る）。区画は見えている幅いっぱい。

## 見つけた事（重い順。どれも直していない）

1. **Surge XT（VST3）の打ちこみ: 上にはみ出す数 ・ 読めない文字が、文なしで端の値（多くは下の端）になり、1 手になる**（4 章 a）。
   - 再現: Surge XT（VST3）のトラック → 右の欄で「Global Volume」をさがす → 値を 2 回押して「3 dB」と打って Enter → −48.00 dB になる（音が消える）。状態行に文は出ない。
   - 原因らしい所: `crates/meloet-plughost/src/formats/vst3.rs` の `ReadText`（`getParamValueByString` の答えをそのまま信じる所と、「打った数と両端の文字の数をくらべる」所）。JUCE は読めない文字にも `kResultOk` と値を返す。打った文字が数で始まらなければ読めないにする、答えの値を文字に戻して打った数とくらべる、などが考えられる。
2. **Surge XT（VST3）で、取り消し ・ やりなおしのあと、欄の値が古い**（4 章 b。音とプラグインは正しい）。
   - 再現: 欄で「A Filter 1 Cutoff」を動かして離す → Ctrl Z → もう一度さがすと、行は動かしたあとの値のまま。
   - 原因らしい所: `vst3.rs` の状態を戻す所（`setState` のあとの `setComponentState`）と `Params` の読み。Surge XT はパッチを音のスレッドの次のブロックで読みこむ。戻したあと 1〜2 ブロック待ってから `setComponentState` と一覧の読みをする、などが考えられる。
3. **窓の中でパッチを変えても、欄の値が変わらない**（4 章 b。一覧の番号が変わらないので、Surge XT は `restartComponent(kParamValuesChanged)` を言ってこないと見ている）。訪問が 1 手になった時に、一覧を古い物にする（取りなおす）と直るはず。ただし 2 が直っていないと、取りなおしても古い。
4. **16 本のトラックでミキサーをひらいて再生すると、メーターのコマが 18〜22 ms かかる**（7 章）。30 Hz でも、WebKit が毎回ページのほとんどを描きなおす。CLAUDE.md の「CPU で描く WebKit」の 25 % の決まりに、横に広いミキサーの区画が当たっている。区画を上の帯と上下でそろえる話ではなく、広さの話なので、作りを考える所。
5. **えらんでいないプラグインのインサートを右クリックすると、窓がひらく。**
   - 再現: ミキサーで、えらんでいない Dragonfly の枠を右クリック → 一覧が出るのと同時に、Dragonfly の窓がひらく（状態行「プラグインの窓が 1 つひらいています」）。とばす ・ 外すために右クリックしただけでも窓が出る。
   - 原因: `ui/src/components/mixer/InsertSlot.svelte` の `context` が、えらんでいない枠に `selectInsert` を送る。プラグインの `selectInsert` は「えらぶ ＋ 窓」（A-17）。右クリックは窓なしでえらぶ、という決めが要る（約束に「えらぶだけ」がない）。
5b. **取り消すたびに、欄のさがす文字とひらいたグループが消える**（4 章 c）。`ui/src/components/params/` の、一覧の番号が変わった時にはじめに戻す所。同じ居場所のプラグインなら残す、が考えられる。
6. 止まった知らせが残っている間、ミキサーのまとめと「窓が N つ」が出ない（5 章 f）。
7. LV2 のプラグインの欄は全角の数字を読まない（4 章 d）。
8. 止まった知らせの文の、名前のうしろの空白（1 章）。
9. はじめてのスキャンが 38.0 秒（区切り2 では 17.5 秒）。子を 1 つずつ起こす形（20-10）の分と見ている。測っただけ。
10. 作業ツリーに `ui/node_modules` の symlink を置くと、git には「知らないファイル」として見える（`.gitignore` はフォルダの形だけを外している）。コミットに入れないよう注意。

## 道具（この回で足した物）

- `crates/meloet-app/src/devhooks.rs`: `MELOET_PIPE=<名前つきパイプ>`。アプリが動いている間、パイプから行を読む。`{"command":{…}}` は意図、`{"js":"…"}` はページの中の JavaScript、`{"shot":"/…/out.png"}` は画面を PNG に（アプリは終わらない）。`MELOET_COMMANDS` は時刻表だけなので、「見てから次の手を決める」道がなかった。
- `tools/measure/remote.py` と `remote_page.js`: 外から本物のアプリを 1 手ずつ動かす。`App`（起動、仮想の鍵盤、出口えらび、`send`、`js`（ページの答えは `measure_report` のファイルで戻る）、`snapshot`、`wait`、`shot`、メモリ）、`X`（ctypes の Xlib で、plughost の窓をさがす、キーボードをわたす ・ 外す、作り物のドラッグ、×）、`Recorder`（出口を録る）、ページの中の作り物のクリック ・ ドラッグ ・ キー。
- `tools/measure/window-rounds.py`: `open-close`（2 章）と `visits`（3 章）。
- `tools/measure/cpu_watch.py`: meloet と WebKitWebProcess の CPU の時間（2 つの時刻の間）。
- `tools/measure/frame_stats.py`: `frame-profile.json` から、ある区間のコマの間 ・ busyMs ・ 区画ごとの描いたコマの数。
- `tools/measure/latency.sh`: `--plugin-window`（トラック 1 の音源のプラグインの窓をひらいたまま測る）。
- `tools/measure/make_song.py`: `--effect-format vst3|lv2`（エフェクトの形式を音源と別に決める）。
- `tools/design/shoot_app.py`: 8 章の 7 つの状態。`typed` はさがす枠を選べる。`context`（右クリック）。
- `README.md`: 開発の変数の一覧に `MELOET_PIPE`。
