# 第 8 回 区切り3 の締め: からっぽの HOME で「はじめての人の 5 分」（2026-11-22、meloet-impl ・ Opus 5.5、印 k8f5）

製品のコードは変えていない。音の素材は本物の GitHub の Release（`sounds-2026.11.2`、組みこんだ目録のとおり）から取った。試験の口（`MELOET_PACK_ORIGIN` ・ `MELOET_PACK_CATALOG` ・ `MELOET_SOUNDS_DIR`）は使っていない。

## 条件

- 版: foundation b30cf61。release（`npm run build` のあと `cargo build --release -p meloet-app -p meloet-midi -p meloet-plughost`、`CARGO_TARGET_DIR=target/k8f5`）。`target/k8f5/release/sounds` はない（開発の包みを見つけない）。
- からっぽの場所: 起動ごとに `target/k8f5-home/<回>/` の下に `HOME`（`home/`）、`XDG_CONFIG_HOME`、`XDG_DATA_HOME`、`XDG_CACHE_HOME`、`XDG_STATE_HOME` を絶対の道で。`MELOET_CONFIG_DIR` ・ `MELOET_STATE_DIR` ・ `MELOET_SONGS_DIR` ・ `MELOET_SF2_DIR` も外した（プラグインのスキャンもはじめから走る）。ほかは `remote.py` のまま（`MELOET_PIPE`、`MELOET_ONLY_VIRTUAL=1`、`MELOET_VKEYS_NAME`、`MELOET_WINDOW`）。
- 動かしかた: スクラッチの `k8f5-first5.py`（`remote.App` を使う）。鍵盤は `meloet-vkeys`。録る・止めるは PC の R と Space をページへ送った（意図を直接送ると「音が出ました」の案内が消えない。人は PC のキーかマウスで録るので、そちらに合わせた）。
- まわり: ほかの係の meloet（`target/k8rt`）と Firefox が同じ出口で鳴っていた。load average は 10〜13（ほかの係のビルド）。**速さの数はにごっている**。回線は速い（グランドピアノ 77 MB が 5〜11 秒）。
- 絵と生の記録: `target/k8f5-shots/`（`*-1280x800.png` ・ `*-853x448.png`、`r1280/`、`*-log.jsonl`、`k8f5-*.out`、試した 3 回 `run0/`〜`run2/`）。モックの PNG は `target/k8f5-mock/`（`render_mocks.py`）。

## 時間

- 「取りにいく」→ グランドピアノが鳴る（`sounds.have` が 6）: **11.5 秒**（1 回め）、5.4 秒、6.5 秒、`watch` 4.9 秒。共通 0.12 MB ＋ グランドピアノ 77.4 MB を取り、sha256、ほどき、読みこみ（stderr「read the sound of grandPiano in 635 ms, 340 MiB」）まで。
- 鳴る音が本当にピアノに変わるのは、画面が `have 6` を見てから 0.2〜0.4 秒あと（録った音で高い音の成分が出はじめた所）。
- 240 MB ぜんぶ: 1 回で通して測っていない。1 回め: 0 → 163 MB が 26.4 秒、次の起動で 165.5 → 239 MB が 22.2 秒。合わせて約 49 秒（この回線で。後ろの小さい音色はファイルの数が多く、1 MB あたりは遅い）。
- からっぽの起動 → 聞く帯（テイク 1 のあと）: この試験の手で 38 秒。人なら録るまでの時間しだい（下の 1）。

## 入れかわりの音（d）

- `remote.Recorder`（出口の monitor）は、ほかの係の meloet と Firefox の音がまざっていたので使えなかった（`d-swap.wav`、すてた）。かわりに `pw-record --target <この meloet の出口のストリーム>` で、この meloet の音だけを録った（起動の前にあった meloet のストリームを除いて見つけた）。
- 和音（C4 E4 G4 C5、ベロシティ 70、250 ms ごと、180 ms 押す）をくり返しながら、取りはじめから入れかわりの 3 秒あとまで録った。2 回とも、入れかわりの前後 ±600 ms に 1 ms の無音（rms < −80 dB）は 0、となりのサンプルとの差の最大は中央値の 3〜4 倍（0.0086〜0.0093。プチッの目安の 8 倍に届かない）。全体でも目立つ跳ねなし。
- **ただし 2 回とも、ピアノの音は和音のくぎりのすき間（−50 dB）のあとの次の鍵から出た**。押している音のとちゅうで 10 ms の重ねが働く瞬間は録れていない（作りでは、押している音はサイン波のまま席が入れかわるので、とちゅうの音がどうなるかは別に見る必要がある。鍵を押したまま入れかわる試験は今回していない）。

## 鍵 → 画面 ・ 鍵 → DAC（g）

`latency.sh --no-build --window 1280x800 --state stopped --commands '{"afterMs":7000,"command":{"type":"fetchPack"}}'`、`XDG_DATA_HOME` をからっぽに（取っている間に 120 鍵。鍵は 7.7〜38.3 秒、取りにいくのは 7 秒から）。くらべに、同じ形で取らない回。どちらも load 13 前後、ほかの係の meloet が動いていた。

| | Rust → 描いた p50 / p95 / max | 2 コマ以内 | Rust → DAC 平均 / p95 / max |
|---|---|---|---|
| 取っている間 | 2.46 / 22.49 / 42.65 ms | 94 % | 13.27 / 15.60 / 15.94 ms |
| 取らない | 1.07 / 2.13 / 16.09 ms | 100 % | 13.28 / 15.77 / 15.91 ms |

- 鍵 → DAC は変わらない（音のスレッドはじゃまされていない）。
- 鍵 → 画面は、取っている間に悪くなった（94 %、2 コマの線をこえた）。遅い鍵は、取りはじめの直後（7.7〜8.5 秒）と 18.8 秒（グランドピアノを読みこむころ）にかたまっていた。にごった条件なので、静かな PC で見なおす価値がある（推論: ほどく所と読みこみの CPU、または 1 秒に 4 回の進みの知らせ）。
- 生の数: `target/k8f5-lat/`（取っている間）、`target/k8f5-lat-base/`（取らない）。

## 見つけた事

1. **はじめての人は、テイクを 1 つ録るまで音の素材を聞かれない**（つまずきそう）。鍵盤をつないで出口を決めると「音が出ました」（SoundCameOut）、それを PC のキーやマウスで消すと「空のアレンジ」（EmptyArrange）の案内が出て、どちらも `workspace.hint` なので、`ui/src/components/pack/pack.ts` の `passingHintUp` が「待てば終わる案内」として聞く帯も状態行の聞く形も出さない。`EmptyArrange` は `crates/meloet-core/src/state.rs` の `empty_hint()` のとおりクリップができるまで（か消すまで）出つづける。鍵盤だけ弾いている人は、MIDI の鍵では「音が出ました」も消えないので、いつまでも聞かれない（60 秒待って出ないのを見た。`run0/`、`run2/`）。この間はずっとサイン波。録ったあとはすぐ帯に出る。B-95-12 は「空のアレンジ」を待てば終わる案内に数えているが、実際は録るまで終わらない。モック F8-PackAsk は、空のアレンジ（クリップなし）で帯に聞く形が出ている。→ 棟梁に: 空のアレンジの案内は「ずっと出ている案内」のほうに数えて状態行で聞くか、聞く帯を空のアレンジの案内より先に出すか（デザインの決めが要りそう）。
2. **取っている間の棚に「音の素材が見つかりません。いまはサイン波だけ使えます。meloet を入れなおすと、もとに戻ります。」が出る**（仕様書 ・ モックとちがう）。85 の文で、取りにいく形の今は意味がちがう（入れなおしても直らない）。モック F8-PackGet にはこの箱がない。サンプルの音色が 1 つもない間（グランドピアノが来るまで）だけ出る。「取りにいく」は押せない形。出どころは `LibraryView::pack_missing`（23-9「前のまま」）と `ui/src/components/Shelf.svelte` の `shelf-notice-pack`。取りにいく係がある間は、まだの音色を「まだ」で見せているので、この箱は出さないのがよさそう（棟梁が決める）。
3. 大きさが「約 239 MB」「ぜんぶあります ・ 239 MB」（目録の 238,909,440 バイト）。仕様書とモックは「240 MB」。数は本物なので、仕様書の文は例として読める（直すかは棟梁）。
4. 置き場所の名前: モック F8-PackSettings は `~/.local/share/meloet/音の素材`、作りは `…/meloet/sounds`（23-1 の決め）。今回は `XDG_DATA_HOME` を `HOME` の外に置いたので絶対の道で出た（`~` にならないのは正しい）。
5. 取っている間、棚の「お気に入り」が 0（グランドピアノ ・ スタジオキットの星は来てから付く）。モック F8-PackGet は「お気に入り 2」。小さい事。
6. 取っている間、状態行は「■ 停止中」だけになることがある（流れの案内も知らせもない間）。帯に出ているので困らない。
7. 「やめる」を押しても状態行は何も言わない（仕様書にも文はない）。

こわれた所（落ちる ・ 固まる ・ 取れない）は見つからなかった。
