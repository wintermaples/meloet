- 生の数: `target/k8mem/m/`（`before/`・`after/` が場面、`long-before/` が 10 分録る、`long-gclog/` が GC の記録つき 4 分、`webgrow*/` ・ `webcanvas/` が WebKit をしらべた回）。歌 16 本の曲は `target/k8mem/songs/vocal16/`（2 分の 24 bit ステレオ 16 本、作り方はスクラッチの `k8mem-vocal16.py`）。

- meloet の RSS の file 149 MB は共有のライブラリ（libLLVM 41、libwebkit2gtk 25、meloet 17、libjavascriptcoregtk 12 …）、gpu 37 MB は NVIDIA の写し。どちらも PSS では小さい（PSS の file は 32〜36）。meloet が自分で持つ物は、サンプルなしで約 40 MB。
- サンプルの数は core が持っている `SampleBank` の `sample_bytes`（i16）。RSS の「anon ＋ arena」と合う（ピアノ 365 MB、8 トラック 702 MB）。
- WebKit の file 175 MB も共有のライブラリ。gpu 50〜60 MB は NVIDIA。ページの中の canvas は 5 枚（1920×1080 で 147〜163 万画素）、DOM は 315〜885。JS のヒープは Full の GC のあとで約 28 MB（`long-gclog`、`JSC_logGC=1`。ヒープの大きさは 90〜100 MB）。WebKit には `performance.memory` がない。
- サンプルの「しっぽ」（ピークから −X dB を最後に下回ったあと。スクラッチの `k8mem-tails.py`、ループのあるファイルは数えない）: グランドピアノ −40 / −50 / −60 dB で 88.5 / 27.7 / 9.3 MiB、スタジオキット 42.0 / 23.2 / 11.5、フィンガーベース 6.9 / 3.2 / 1.7（どれも 5 秒で、音が残っている）、ストリングスとオルガンはループなので 0。

## 2. 手放したサンプル（直した所）

`letgo`: `band8-all` をひらく → トラックを全部消す → 取り消しで全部もどす → 新しい曲（保存しない）→ 棚でストリングスをためし弾き → 棚を閉じる。各手のあと読みこみが終わってから 15 秒。

| 手 | 持っているサンプル（MiB） | 直す前 RSS（`before/`） | 直したあと RSS（`after/`） |
|---|---|---|---|
| ひらいた | 674 | 900 | 908 |
| トラックを全部消した | 0 | 374 | **231** |
| 取り消しで全部もどした | 674 | 1060 | **902** |
| 新しい曲 | 340 | 1051 | **573** |
| ストリングスをためし弾き | 417 | 1077 | **650** |
| 棚を閉じた | 340 | 1059 | **573** |

- 直す前は、手放したサンプルのメモリが malloc の中に残った（読む係のスレッドの arena）。取り消しで読みなおすと、こんどは大きな塊が arena に入り（malloc の「単独で取る」大きさの線が、はじめに手放した塊の大きさまで上がるため。glibc の動き、確かさ C）、閉じても返らない。**新しい曲で 1051 MB（サンプル 340 MiB）**。
- 直したあと: 手放したバイト数を `SampleBank` の `Drop` で数え、4 MiB をこえたら別のスレッドで `malloc_trim(0)`。どの手のあとも、持っているサンプル ＋ 約 230 MB にもどる。`malloc_trim` は 1 回 0.2〜24.8 ms（`after/letgo/raw/meloet.stderr` の「gave back」の行。334 MiB で 24.8 ms）。
- `mallinfo2` の「空き」は返したあとも大きいまま（428 MiB）。返したページは malloc の帳簿では空きのままで、RSS からは消える（`madvise`）。
- `malloc_trim` が arena のまん中のページも返すことは、RSS が下がったことで確かめた（確かさ A、この PC の数）。glibc のソースは読んでいない（入れた版は 2.43）。

## 5. 宿題（棟梁に）

1. **WebKit の CPU の道でのふえかた**: (a) 合成の道にもどす（鍵 → 画面が p50 で 8〜10 ms 長くなる、`round8-quiet` の理由 1）、(b) CPU の道のまま、ふえる物を見つける（WebKit 2.52.6 の CPU で描く道のソースを読む。ページの描く物を減らしてためす）、(c) 1 時間測って止まるかを見てから決める。私は (c) のあと (b) をすすめる（確かさ C）。
2. サンプルを減らすのは、包みを作る所（`tools/sounds/`）で、オーナーさんの耳が要る: グランドピアノのしっぽ（−50 dB で −28 MiB、−40 dB で −88 MiB）、スタジオキットのしっぽ（−50 dB で −23 MiB）、ストリングスのループを短く（いま 6〜17 秒の所から）。
3. glibc の arena は 40〜72 個（スレッドが多い）。返す形にしたので RSS にはひびかないが、数は減っていない。
