# ループ中の録音を、本物の ALSA シーケンサを通して（2026-11-15）

- 試験: `crates/meloet-core/tests/record_loop_private.rs`（`cargo test --release -p meloet-core --test record_loop_private -- --ignored --nocapture`）。自分用の PipeWire と WirePlumber（null sink）で `Core` を動かし、試験用の名前の仮想の鍵盤を `MELOET_VKEYS_NAME` と同じ形（`MidiOptions::virtual_names`）でだけ受ける。
- 条件: 96.00 ではなく 120.00（1 ミリ秒 = 0.96 ティック）、4/4、ループ 2–4 小節（ティック 1920〜5760、1 周 4 秒）、カウントイン 1 小節、メトロノームあり。押す時刻は、計器 v2 の位置から出して、その時刻まで待って押す（録った位置の道具と同じ）。
- 3 回走らせて、3 回とも通った。

| いつ（周・位置） | 何をしたか | 決まり（`docs/architecture.md` 13 章） | 結果 |
|---|---|---|---|
| 録りはじめる 50 ms 前（カウントイン中） | 60 を押し、録りはじめの 100 ms 後に離す | 最初の周だけ、直前に押した鍵まで前へ広げる | 1 周目のテイクに 1872（= 1920 − 48）から入り、テイクはそこから始まる（offset 0、クリップ 1872〜5760） |
| 1 周目 2880 | 62 を押して 120 ms で離す | | 1 周目に 2880、長さ 115 |
| 1 周目 3840 | ペダルを踏み、2 周目 4320 まで踏んだまま | 踏んだままのペダルは次の周の頭に書く | 1 周目: 3840 に CC64 127。2 周目: 1920（周の頭）に CC64 127、4320 に CC64 0 |
| 1 周目の終わりの 25 ms 前 | 64 を押し、2 周目に 200 ms 入ってから離す | 押した周に入れ、ループの終わりで切る | 1 周目に 5736、長さ 24（5760 で切れた）。2 周目には入らない |
| 2 周目の頭の 25 ms 後 | 65 を押して 100 ms で離す | | 2 周目に 1944、長さ 96 |
| 3 周目 | 何もしない | ノートのない周はテイクにしない | テイクなし |
| 4 周目 2880 | 67 を押して 120 ms で離し、3840 で止める | 止めたら、ノートのある最後の周を見せる | テイクは 3 つ（1・2・4 周目）。見せているのはテイク 3（4 周目） |

- 位置のずれは、どれも 1 ティック以内（判定は ±3 ティック）。
- 4 周目のテイクの長さは 1920（止めた所まで）。2 周目は 3840（1 周ぶん）。1 周目は 3888（前へ広げた 48 の分だけ長い）。
