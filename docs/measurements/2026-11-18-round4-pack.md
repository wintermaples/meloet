## 素材ごとの作りかたと、決めたこと

### どのファイルにも

- 頭の無音: 左右の大きいほうがピークから −50 dB をこえる 2 ms 前から切り、1 ms のフェードイン（19-8）。切った長さはオルガンで 25〜38 ms、ほかの多くは 0〜数 ms。
- ピーク −1 dBFS まで持ち上げて 16 bit（丸め、ディザなし。19-7 と同じ）。その分と SFZ の `volume` を、リージョンの `gainDb` に入れた。
- サンプルレートはファイルのまま（クラップだけ 48 kHz、ピアノも 48 kHz、ほかは 44.1 kHz）。

### グランドピアノ（Salamander、`SalamanderGrandPiano-V3+20200602.sfz`。Retuned は使わない）

- 4 段 v2 ・ v8 ・ v12 ・ v16 を 1–34 ・ 35–64 ・ 65–96 ・ 97–127 に。リリース音 88、共鳴 69（3 組、ベロシティの範囲と `amp_veltrack`・`rt_decay`・`volume` は SFZ のまま）、ペダル 4。
- **段ごとの `ampVeltrack` と `gainDb` は、16 段のときの鳴りかたに合わせて決めなおした**（棟梁の知らせ 1）: 16 段の各段の真ん中のベロシティで、その段のファイルのピーク ＋ SFZ の `amp_veltrack=73` の曲線を点にし、点の間を直線でつないだ物（ベロシティにつれて下がらないように）を「目あて」にした。残す 4 段のそれぞれで、`ampVeltrack` を 0〜100 で 1 きざみにためし、段の範囲の目あてとの差の 2 乗が最小になる物と、そのときの dB のずれを選ぶ（段の両はしの 2 つずつを 8 倍に重くし、となりの段との境の段差を小さくする）。鍵の音（30 音）ごとに別に決めた。目あてとの差は全体で 0.93 dB（重みつきの RMS）。
  - 境（34/35 ・ 64/65 ・ 96/97）の段差は、88 鍵 × 3 か所の中央で +1.4 dB、最大 +6.0 dB（A7〜C8 の 96/97 と A5 の 34/35）。高い所は、目あての上がりかたが `ampVeltrack` 100 の曲線より急で、合わせきれない（`ampVeltrack` は 100 まで）。
  - SFZ のベロシティの曲線（音量 ＝ (1 − t) ＋ t × (v/127)²）は、鳴らす係の `player.rs` と同じ式で計算した。
- `ampeg_release` は鍵 21〜88 が 1000 ms、89〜108 が 5000 ms（SFZ）。リリース音・共鳴・ペダルは SFZ に書いていないので `releaseMs` を書かず、鳴らす係のはじめの 200 ms になる。
- ペダルの 4 つ: `trigger` は `pedalDown`（CC64 が 126〜127 になった時）と `pedalUp`（0〜1）。SFZ の `lorand`・`hirand`（2 つから 1 つを無作為）は 19-8 に欄がないので、`rrIndex`・`rrCount` 2 の順番にした。`keyLo` 0 〜 `keyHi` 127、`root` 60、`pitchKeytrack` 0、`ampVeltrack` 0（ペダルにベロシティはない）。踏む音は離す音で止まる（SFZ の `group=1 off_by=2`）ので、`chokeGroup` 1 ・ `chokedBy` [2]、離す音は `chokeGroup` 2。
- 大きさ: C4 ・ ベロシティ 100 は v16 の段（97–127）。

### エレクトリックピアノ（Wurlitzer、Greg Sullivan）

- **.gig のループ点は使えなかった**: 作者のページの「Download wurlitzer_ep200.rar」は `/downloads` に行き、そこは Google ドライブのフォルダ（`folderview?id=1lRojKMYct3uXZ07rgFwqsA0jzW3ZgZdD`）を埋めこんでいるだけで、ログインなしで取ると Google のログインの画面が返る。古い道（`sullivang.net/samples/…`、`/sample-files/wurlitzer_ep200.rar`）は 404、Wayback Machine には転送の記録しかなかった。sha256 は記録できていない（`sources.json` の `loop_points` に書いた）。.gig を読む道具は書いていない。
- かわりに、どのファイルも**終わりのところに交差のループ**を作った（下の「ループの作りかた」）。ループの長さは 0.05〜0.24 秒、交差 20 ms。
- `loopDecayDbPerS`: ファイルの後ろ 6 割（はじめの 80 ms は除く）の 50 ms ごとの大きさ（dB）に直線を引き、その傾き。低い音 1.2〜3.7 dB/秒、高い音 19〜26 dB/秒。ループの中は、その減りを打ち消してから（大きさを平らにしてから）焼きこみ、鳴らすときに `loopDecayDbPerS` で同じ速さで小さくする。
- SFZ の値: `amp_veltrack` は CC99（はじめ 1）で 100、`ampeg_release` は CC72（はじめ 0.05）× 2 ＝ 100 ms、`attack` 1 ms、`volume`・`tune`・鍵の範囲・4 段はそのまま。SFZ の hold 5 秒 ・ decay 25 秒（鍵が高いほど短い）は写していない（ループの減りで代わりにする）。
- 同じファイルを別の段で使う所（pp の高い音が mp のファイル）は、ファイルは 1 つで、リージョンが 2 つ（48 リージョン、42 ファイル）。

### フィンガーベース（Black And Blue Basses、`05-darkblack_pluck.sfz`）

- 中央の、ポリの組だけ（`hicc105=63`、`locc100` の左右のユニゾンは外す。CC の条件は SFZ の `set_cc` の値で見た）。4 段 × テイク 2（`seq_position` 1 と 2）。`keyLo`・`keyHi`・`root` を 12 下げた（23〜64）。
- 最後の 100 ms を半分のコサインでフェード。リリース音はつけない。
- `releaseMs` 250（SFZ）、`volume` +3 dB（SFZ）。
- **`ampVeltrack` は 50 にした**: SFZ は段ごとにベロシティの曲線を作りなおしている（`amp_velcurve_31=1` など。p の段は 1〜31 で 0 から 1 へ直線）。19-8 の形は 1 つの曲線しか書けないので、段の大きさ（録った強さ）を生かし、段の中は ±数 dB だけ変わる値にした。聞いて決めたい。
- SFZ のローパス（はじめの値で 7〜9 kHz あたり、C）、ビブラート、ユニゾンは焼きこんでいない。

### スタジオキット（Naked Drums ＋ VCSL のクラップ）

- 作者の GM の組み（`User/Naked Drums GM.sfz`）を `sfz_flat` でほどき、SFZ の `set_cc`・`set_hdcc` の値で、直のマイク（CC41 ＝ 0.5 → 100 %）、オーバーヘッド（CC42 ＝ 0.5 → 100 %）、太鼓ごとの量（CC20〜31。HH とライドの直は 0.1 → 20 %、−14 dB）、パン（CC32〜40）と、`master_volume ＋ group_volume ＋ volume`（段ごとの持ち上げ、たとえばキックの OH の弱い段 +24 dB をふくむ）を出して、ステレオにまぜた。
- モノの直のマイクのパンは等パワー（真ん中で左右とも 1 倍、片側によせるとそちらが 3 dB 大きい。鳴らす係の `pan` と同じ形）。タムの直は Tom1 が左 −0.6、Tom5 が右 +0.6（作者の値。叩く人から見た並び）。
- 12 の音: キック 36（5 段）、サイドスティック 37、スネア 38（5 段）、クラップ 39、クローズ HH 42（Tight、3 段）、ペダル HH 44、オープン HH 46（3 段）、ロータム 45 ＝ Tom5、ミッドタム 47 ＝ Tom3（`tuneCents` −200 は作者の値）、ハイタム 50 ＝ Tom1、クラッシュ 49（OH だけ）、ライド 51（Bow）。テイクは `seq_position` 1〜4。
- `oneShot`、`ampVeltrack` 99（SFZ）。42 と 44 は `chokeGroup` 1、46 は `chokeGroup` 2 ・ `chokedBy` [1]、止められたときの消えかた `releaseMs` 200（SFZ の `off_time` 0.2）。
- **クラップ**（VCSL の Clap_rr1〜6、48 kHz）: 作者の組みがないので、ベロシティ 100 のピークが、スネアの同じベロシティの段のピーク（4 テイクの最大）と同じになるようにした。`ampVeltrack` 99、テイク 6。

### ストリングス（VSCO 2 CE）

- **鍵の分けかた**: 重ねずに、低い楽器から順に、次の楽器のいちばん低い音の手前まで: コントラバス（ソロ、ビブラート）24〜35、チェロ（セクション）36〜47、ヴィオラ（セクション）48〜54、ヴァイオリン（セクション）55〜86。SFZ のリージョンをこの範囲で切った（47 ファイル）。理由: どの鍵でも 1 つの楽器だけが鳴り、音の高さに無理がない（それぞれの楽器のいちばん低い音まで使う）。ヴィオラが 7 鍵しかないので、重ねる形（たとえばチェロとコントラバスを 1 オクターブで重ねる）は聞いてから。
- 2 段（v1 0–62 → 1–62、v2 または v3 63–127）、`volume`（v1 +16〜+28 dB）、`ampeg_release` 800 ms、`attack` 1 ms、`amp_veltrack` 100（SFZ のはじめの値）。
- ループ: 下の「ループの作りかた」の「落ちついた所」。

### オルガン（VCSL のパイプオルガン、手鍵盤）

- `--organ loud`（Loud/ ＝ Rode_Man3Open、はじめ）か `--organ quiet`（Quiet/ ＝ NT5_Man3Quiet）。どちらも `kind` は `organ`。ファイル名の C3 ＝ 60 で、21 音（C1〜C6、短 3 度ごと）を、その鍵 ±1 に（両はしは片側だけ）。鍵 36〜96。
- `ampVeltrack` 0（パイプオルガンは鍵の強さで音が変わらない）、`attack` 1 ms。
- `releaseMs`: 録ってある「鍵を離した」所から、のびていた大きさより 60 dB 下がるまで（部屋の響きをふくむ）を、真ん中の音（F#3）で測った: loud 1140 ms、quiet 2200 ms。ファイルはループの終わりで切るので、録った響きは使わない。
- **大きさは和音で決めた**（棟梁の知らせ 2）: オルガンの音は、のびている間ずっと大きいままなので、和音で大きく足される。quiet は 1 つの C4 で −12 dBFS にすると、和音が +0.3 dBFS でふりきれた。render_pack の和音（C3 の下に C4 ・ E4 ・ G4、ベロシティ 100）を、build.py の中で見積もり（ファイルを線形の補間で鍵の高さに動かし、鳴らす係と同じ倍率で足す）、そのピークが **−9 dBFS** になるように楽器の `gainDb` を決めた。見積もりは render_pack とよく合った（前の gainDb で loud −7.5 / 実際 −7.6、quiet +0.05 / +0.3。直した後のフレーズ loud −9.1、quiet −8.8）。1 つの C4 は loud −13.5、quiet −21.1 dBFS になる。

### 大きさの決めかた（楽器の `gainDb`）

- C4（ドラムはキック 36）・ベロシティ 100 で鳴るアタックのリージョンのうち、いちばん大きい物のピークを `−1 dBFS（ファイル）＋ リージョンの gainDb ＋ ベロシティの曲線` で見積もり、−12 dBFS との差を楽器の `gainDb` にした（0.1 dB 単位）。音の高さを変えることと、リリース音・共鳴は入れない。モノのファイルは左右とも 1 倍で鳴る（鳴らす係の `pan` 0）として見積もった。オルガンだけは上の和音で −9 dBFS。
- render_pack で、ストリングスの C4 のばしは −12.0 dBFS、ピアノの C4 v127 は −8.2（見積もり −7.9）で、見積もりと 0.3 dB 以内だった。

## ループの作りかた

1. 頭の無音を切った後のファイルで、ループの終わり `le` を決める。
   - エレクトリックピアノ: ファイルの終わりの 2 ms 前。
   - ストリングス ・ オルガン: 50 ms ごとの大きさの、真ん中の半分の中央値を「のびている大きさ」とし、そこから −3 dB 以内に入った所 ＋ 0.3 秒（かつ 1 秒より後）を「落ちついた所」の始まり、−6 dB 以内にいる最後の所 − 0.3 秒を終わり（弓が止まる前、鍵を離す前）。そこを `le` に。
2. ループの長さの目あて（ストリングス ・ オルガン: 落ちついた長さの 7 割、最大 4 秒、±0.25 秒。エレクトリックピアノ: 0.05〜0.5 秒）の中で、`le` の前の交差の長さぶんのこまと、いちばん形が似ている所（正規化した相関。FFT で計算）の後ろを、ループの始まり `ls` にする。
3. ループの中に、始まりから終わりへ、大きさを直線（dB）で変えるゲインをかけ、終わりの大きさを始まりにそろえる（エレクトリックピアノは、測った減りを打ち消す）。
4. ループの終わりの交差の長さぶん（`le − X` 〜 `le`）を、始まりの前（`ls − X` 〜 `ls`）と交差させて焼きこむ（相関が 0.8 より大きいときは直線、ほかは等パワー）。こうすると `le − 1` の次に `ls` を鳴らしても、もとの `ls − 1` から `ls` へ進むのと同じになる。
5. ファイルは `le` で切る。`loopEnd` ＝ `le` ＝ ファイルのこまの数（最後に鳴らすこまの次）。
