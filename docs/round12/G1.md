# G1: the key list and the link to the user guide

## Architecture

- **Opening the guide (Rust).** `Command::OpenUserGuide` makes core push `Effect::OpenUrl(USER_GUIDE_URL)`; the service turns it into `ShellRequest::OpenUrl { url }`, and `meloet-app` runs `pcwindow::open_url` (`xdg-open` on its own thread, `https://` only). The address lives in one place, `meloet_core::state::USER_GUIDE_URL`; the screen never sends an address. D4 can turn the constant into a choice by language there. `Effect::OpenUrl(String)` is a new core-inside effect (not a protocol shape). D1 (「リリースのページ」) and E9 can reuse it.
- **The table (screen).** `ui/src/keys/keyList.ts` writes spec 4 by hand as rows of (group, wording key, keys). `ACTION_ROWS` is a `Record<KeyAction["kind"], readonly KeyRow[]>`: a `KeyAction` kind added to `keys.ts` without an entry here fails `npm run check` (checked by hand: taking out `menuBar` gives "Property 'menuBar' is missing"). An empty list is allowed and means "not shown" (only the output chooser's ↑ ↓ Enter). `OTHER_ROWS` holds the keys spec 4 lists that are taken outside `keys.ts` (markers, tempo box, mixer focus keys, parameters panel, drags, Tab). `WAVE2_ROWS` holds the three keys of wave 2 (see Readings). Keys are written by `keyNames(platform)` of `menus.ts` (one `alt` writer was added there for 「Alt →」/「Option →」).
- **The dialog.** `components/keylist/keyList.svelte.ts` (state: open, query, folded groups) and `KeyListDialog.svelte`, copied from 「meloet について」: placed in `App.svelte` beside `AboutDialog`, `status.dialogOpen` in `StatusLine.svelte`, and `keyListBack()` right after `aboutBack()` in the Esc branch of `keys/attach.ts`. A screen-only dialog like About: core does not hold it, the protocol does not change.
- **One screen dialog at a time.** In the Help menu, 「キーの一覧」 is disabled while About is open and the other way round (and both while a core dialog is open), so the Esc order stays single.
- Trap: the shoot scenes of About clicked Help row 0; the menu now has 4 entries (separators count in `data-row`), so About is row 3 (`tools/design/shoot_ui.py`).

## Spec rules

- `docs/spec/3-bands.md`, "Rules added in round 12": the Help menu has 「キーの一覧」, 「使い方をひらく」, a separator, 「meloet について」 (replaces L86 「meloet について」 only).
- 「キーの一覧」 is a dialog: groups 曲とファイル / 再生と録音 / 帯 / アレンジ / ピアノロール / ミキサー / 表示 in that order, each with a ▾ heading that folds; a filter box on top (placeholder 「さがす…」) that looks at the row words, the keys and the group name; groups with a match open while something is typed; opening again starts with nothing typed and nothing folded. Keys are written the same way as in the menus (Ctrl / Cmd, Alt / Option). Foot: 「使い方のページをひらく」 (link, left) and 「閉じる」 (right). Esc closes it (after drag cancel, menus and About in the Esc order; in the filter box, the first Esc only leaves the box). The status line says 「キーの一覧 をひらいています」.
- 「使い方をひらく」 and 「使い方のページをひらく」 open `https://github.com/wintermaples/meloet/blob/main/docs/user/README.ja.md` in the PC's browser. Rust holds the address.
- `docs/spec/4-keys.md`: no key added by G1. Rule for later rounds: a key added to `keys.ts` must get a row in `ui/src/keys/keyList.ts` (the type check asks for it); a key taken outside `keys.ts` goes into `OTHER_ROWS` by hand.
- No new step names.

## Readings

- **Edit keys in two groups.** The spec's groups have no 「編集」. Cut, copy, paste, duplicate, select all and Delete work on whichever of the arrange and the piano roll was pressed last, so they are listed under both アレンジ and ピアノロール. Undo and redo are under 曲とファイル.
- **Where the rest went.** Esc, the shelf keys and the history band keys: 帯. Markers, tempo box, drags (Alt / Shift + drag, Esc to cancel): アレンジ. Note list Enter / Tab: ピアノロール. Fader / pan / send keys and the parameters panel keys: ミキサー. Zoom, screen scale, vertical zoom (Mod Shift ＋ wheel), F10, Tab: 表示. The output chooser's ↑ ↓ Enter are not listed (they only work inside the chooser, whose hint says them).
- **Rows that join two menu rows** use 「 ／ 」 between them (from the spec's figure 「再生 ／ 止める」): 「次のテイク ／ 前のテイク」, 「横に拡大 ／ 横に縮小」, 「縦に拡大 ／ 縦に縮小」. Key alternatives are joined the same way (「T ／ Shift T」, 「Ctrl Alt 1 ／ 2 ／ 3」).
- **Q is 「クオンタイズをかけなおす」** as in the spec's figure (the menu row stays 「クオンタイズ」).
- **Wave 2 keys.** The type design allows rows without a `KeyAction`, so Shift R 「さっきのを残す」 (再生と録音), Mod K 「キーで弾く」 (再生と録音) and Mod R 「クリップをくり返す」 (アレンジ) are in `WAVE2_ROWS`, already shown. When R1, R2 and A1 add their `KeyAction` kinds, the type check asks them for an `ACTION_ROWS` entry; they move the row there and take it out of `WAVE2_ROWS`. Their wording keys `keyList.keepLast`, `keyList.playByKeys`, `keyList.repeatClips` and key names `key.keepLast` (R), `key.playByKeys` (K), `key.repeatClips` (R) are in `ja.ts` and can be reused.
- **The link** is accent-colored text in the foot (the figure's 「a」 color), not a button. The filter box sits in its own row under the heading (like About's second page), not in the heading row of the figure.
- **Wording from the spec** (`user:2026-11-23`): 「キーの一覧」 (menu and title), 「使い方をひらく」, 「さがす…」, 「使い方のページをひらく」, 「 ／ 」, the 7 group names, 「再生 ／ 止める」, 「クオンタイズをかけなおす」, 「さっきのを残す」, 「キーで弾く」, 「クリップをくり返す」. Key names from spec 4 (`spec:4`): ↑ ↓ ← → F10 Tab K F ＋ ホイール ドラッグ.
- **Wording made up** (`builder:2026-11-23`, all in `ja.ts` under `keyList.*`): 「ひとつ戻る ／ 閉じる」, 「メニューバーへ」, 「次のボタンや欄へ ／ 前へ」, 「トラック ／ クリップの名前を変える」, 「道具：選ぶ ／ 書く ／ 消す」, 「ノートを半音 ／ 1 オクターブ動かす」, 「ノートをグリッド 1 つ動かす」, 「ノートの一覧：欄に打ちこむ ／ 右の欄へ」, 「複製しながら動かす」, 「グリッドに合わせずに動かす」, 「ドラッグをやめて元に戻す」, 「マーカーを足す」, 「次のマーカーへ ／ 前のマーカーへ」, 「マーカーの名前を変える」, 「選んだ点 ／ マーカーを消す」, 「テンポ ／ 拍子の箱で 1 ／ 10 ずつ変える」, 「棚：上 ／ 下の行を選ぶ」, 「棚：選んだ音を入れる」, 「棚：サンプルを鳴らす ／ 止める」, 「棚：お気に入りの印」, 「履歴：上 ／ 下の行を選ぶ」, 「履歴：いまのステップへ」, 「履歴：ここまで戻す」, 「選んだインサートをとばす ／ 戻す」, 「選んだインサートを外す」, 「フェーダー ／ センドを動かす（細かく）」, 「パンを動かす（大きく）」, 「フェーダー ／ パン ／ センドを最初の値に戻す」, 「フェーダー ／ パン ／ センドに値を打ちこむ」, 「パラメータ：上 ／ 下の行を選ぶ」, 「パラメータ：値を動かす（細かく）」, 「パラメータ：値を打ちこむ」, 「パラメータ：さがす箱へ」.
