## メーターとフェーダーの目盛

メーターとフェーダーは同じ目盛を使う。長さは、いちばん下（横のメーターは左はし）を 0 %、いちばん上を 100 % として、下の点を直線でつなぐ。−60 dB より小さい音は 0 %（−∞）。メーターは、上がるときはすぐ、落ちるときは 20 dB を 1.7 秒かけて。0 dB をこえたら、上はしに rec の 2px を 2 秒。

| dB | +6 | 0 | −3 | −6 | −12 | −24 | −60 |
|---|---|---|---|---|---|---|---|
| 長さ | 100 % | 80 % | 70 % | 60 % | 40 % | 20 % | 0 % |
