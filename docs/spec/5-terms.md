# 5 Term tips

Shown when the mouse stays still for 0.6 seconds on a term that appears for the first time. The form is 「用語 — 説明」. The words on the screen keep the names that are common in the world; the explanations are made easy instead.

| Term | Explanation wording |
|---|---|
| ソロ（書き出し） | ソロは聞くための物なので、書き出しには入らない。ソロのとおりに書き出したいときは、ミュートか「トラックごと」で。 |
| 音の素材の包み | グランドピアノなど 31 の音色の音。meloet には入っておらず、はじめて起動したときに取りにいく（約 240 MB）。 |
| モニター | 入ってくる自分の声を、meloet を通してヘッドホンで聞くこと。少し遅れて聞こえる。 |
| 波形 | 音の大きさを、時間にそってならべた形。 |
| 入口のチャンネル | 音の入口の番号。マイクが 1 本ならモノ（入口 1）、2 本ならステレオ（入口 1 ・ 2）。 |
| のび縮み | 音の高さを変えずに、音を長く ・ 短くすること。タイムストレッチとも呼ぶ。 |
| セント | 半音を 100 に分けた、音の高さの細かい目盛り。 |
| 声の感じを保つ | 音の高さを変えても、声が子どものように ・ 低い声のようにならないようにする。フォルマントとも呼ぶ。 |
| この音のテンポ | その音のファイルを作ったときのテンポ。曲のテンポとくらべて、のび縮みの量を決める。 |
| しっぽ | 音を止めたあとに残る響き。書き出しでは、これが消えるまで書く。 |
| 休み（オートメーション） | 手で動かしたので、オートメーションがそのパラメータを動かすのを休んでいること。「もどす」で線のとおりに戻る。 |
| だんだん | テンポを、ある点から次の点まで、少しずつ変えていくこと。 |
| 手 | 取り消し ・ やりなおしの 1 回分。ドラッグ 1 回、ボタン 1 回が 1 手。 |
| テンポの変更 | 曲のとちゅうで、速さを変える所。 |
| 拍子の変更 | 曲のとちゅうで、1 小節の拍の数を変える所。小節の頭でだけ変えられる。 |
| とばす | エフェクトを外さずに、音がそこを通らないようにする。かける前と後をくらべるのに使う。ほかでは「バイパス」とも呼ぶ。 |
| 作った人 | プラグインを作った人や会社。プラグインが自分で言ってくる。 |
| SF2 | 音色がたくさん入った 1 つのファイル。サウンドフォントとも呼ぶ。 |
| GM | 音色の番号の、世界共通の決まり。1 番がピアノ、ドラムは決まった鍵に決まった楽器。 |
| サイン波 | いちばん単純な、まるい音。音の高さを確かめるのにむいている。 |
| キック | いちばん低い、足で鳴らす大きな太鼓。バスドラムとも呼ぶ。 |
| スネア | 「タン」と鳴る、手前の小さな太鼓。 |
| サイドスティック | スネアのふちを、ばちで「コッ」と鳴らす音。 |
| クラップ | 手をたたく音。 |
| タム | 音の高さのちがう、まるい太鼓。ハイ ・ ミッド ・ ロー ・ フロアがある。 |
| ハイハット | 2 枚のシンバルを合わせた物。とじて「チッ」（クローズ）、ひらいて「シャー」（オープン）、ペダルで「チャッ」（ペダル）。 |
| クラッシュ | 曲の区切りで「ジャーン」と鳴らすシンバル。 |
| ライド | 「チーン」と刻む、大きなシンバル。 |
| リバーブ | 部屋の響きを足すエフェクト。 |
| ディレイ | やまびこのように、音をくり返すエフェクト。 |
| EQ | 音の高さごとに、大きさを上げ下げするエフェクト。イコライザーとも呼ぶ。 |
| コンプレッサー | 大きい音をおさえて、音量をそろえるエフェクト。 |
| リミッター | 決めた大きさをこえないようにして、音割れを防ぐエフェクト。 |
| コーラス | 音を少しずらして重ね、厚みを出すエフェクト。 |
| 響きの長さ | 響きが消えるまでの時間。ほかのリバーブでは「ディケイ」「リバーブタイム」とも呼ぶ。 |
| 部屋の大きさ | 響く部屋の広さ。ほかのリバーブでは「サイズ」「ルームサイズ」とも呼ぶ。 |
| プリディレイ | 元の音から、響きが始まるまでの時間。 |
| 高い音を落とす | この高さより上の音を弱くする。ほかでは「ハイカット」とも呼ぶ。 |
| 低い音を落とす | この高さより下の音を弱くする。ほかでは「ローカット」とも呼ぶ。 |
| 広がり | 響きの左右の広さ。ほかでは「ワイズ」「ステレオ幅」とも呼ぶ。 |
| ミックス | 元の音と、エフェクトの音の混ぜかた。トラックとマスターでは、はじめ 30 %、戻りでは 100 %。ほかでは「ドライ ・ ウェット」とも呼ぶ。 |
| 間隔 | くり返すまでの時間。 |
| テンポに合わせる | オンなら、間隔を曲のテンポの音符の長さで決める。 |
| くり返し | くり返しの回数の多さ。ほかのディレイでは「フィードバック」とも呼ぶ。 |
| 左右にゆれる | くり返す音が、左右に交互に鳴る。ほかでは「ピンポン」とも呼ぶ。 |
| 取り消しの履歴 | これまでにした手の一覧。どこまで取り消したかが見える。 |
| ベロシティ固定 | 鍵盤をどの強さで押しても、決めた強さで鳴らして録る。書く道具のノートも同じ強さになる。 |
| なおすためのファイル | PC が急に終わったときのために、保存していない変更を急いで書いておくファイル。次に起動したとき、ここから戻せる。 |
| トラック | 楽器ひとつぶんの列。音源をひとつ持つ。 |
| クリップ | トラックの上に置く、ひとかたまりの演奏や録音。 |
| アレンジ | トラックとクリップを時間にそってならべる、曲の全体図。 |
| ピアノロール | 縦が音の高さ、横が時間の方眼。ノートを一つずつ直す場所。 |
| ミキサー | 各トラックの音量や響きをまとめて整える卓。 |
| ノート | 鍵を押してから離すまでの 1 音。位置、長さ、高さ、ベロシティを持つ。 |
| ベロシティ | 鍵盤を押した強さ。1 がいちばん弱く、127 がいちばん強い。 |
| MIDI | 音そのものではなく、「どの鍵を、いつ、どの強さで」という演奏の記録。あとから直せる。 |
| CC | コントロールチェンジ。ペダルやホイールなど、鍵盤いがいの動きの記録。番号で種類が決まっている。 |
| サステイン | 足のペダル（CC 64）。踏んでいる間、音がのびる。 |
| ピッチベンド | 音の高さをなめらかに上下させるホイール。 |
| モジュレーション | 音にゆれを足すホイール（CC 1）。 |
| テンポ | 曲の速さ。4 分音符が 1 分間に何回か（BPM）。拍子が 6/8 でも 4 分音符で数えるので、拍子を変えてもテンポの数は変わらない。6/8 の 1 拍（付点 4 分音符）は、テンポ 120 なら 1 分間に 80 回。 |
| 拍子 | 1 小節に拍がいくつ入るか。4/4 は 4 拍。 |
| 小節 . 拍 . ティック | 曲の中の位置。ティックは、4 分音符を 1920 に分けた細かい目盛り（4 けた）。 |
| メトロノーム | 拍に合わせて鳴るクリック音。 |
| カウントイン | 録音が始まる前に鳴る合図の拍。 |
| ループ | 決めた範囲をくり返し再生する。 |
| マーカー | 曲の中の場所につける名札。 |
| テイク | 同じ場所を録りなおした 1 回ぶん。前のテイクも消えずに残る。 |
| 録音待機 | 録音ボタンを押したとき、このトラックに録る、という印。 |
| グリッド | ノートやクリップが吸いつく時間の目盛り。1/16 は 16 分音符。 |
| 三連符 | 1 拍を 3 つに分けるグリッド。 |
| クオンタイズ | 弾いたタイミングをグリッドにそろえる。強さで、どれだけ寄せるかを決める。 |
| スウィング | 裏拍を少し後ろへずらして、はねたノリにする。 |
| スケール固定 | えらんだ音階の音だけに書きこめるようにする。 |
| ミュート | このトラックの音を消す。 |
| ソロ | このトラックだけを聞く。 |
| パン | 音を左右のどこに置くか。 |
| フェーダー | 音量を上げ下げする、縦に動かすつまみ。 |
| dB | 音の大きさの単位。0 が基準で、マイナスが大きいほど小さい。 |
| メーター | いま鳴っている音の大きさ。いちばん上まで届くと音が割れる。 |
| マスター | すべてのトラックが最後に集まる出口。 |
| インサート | エフェクトをさしこむ枠。上から順に音が通る。 |
| センド | 音の一部を、みんなで使うエフェクトへ送る道。 |
| 戻り（リターン） | センドで送った音が、エフェクトを通って帰ってくるチャンネル。 |
| オートメーション | つまみの動きを時間にそって書いておく機能。 |
| プラグイン | あとから足せる音源やエフェクト。中の画面は、作った人ごとに見た目がちがう。 |
| 音源 | 鍵盤を弾いたときに鳴る楽器の役。 |
| サンプル | その音色で、決まった短いフレーズを鳴らす見本。棚の ▶ で聞ける。 |
| ためし弾き | 棚で音源をえらんでいる間だけ、鍵盤がその音色で鳴ること。トラックには入らない。 |
| お気に入り | 星の印をつけた音源。棚の「お気に入り」でまとめて出せる。 |
| エフェクト | 音に響きや変化を足す役。 |
| パラメータ | プラグインが持っている、動かせる値のひとつひとつ。つまみやスイッチにあたる。 |
| プラグインの窓 | プラグインが自分で持っている画面。meloet の外に、別の窓としてひらく。 |
| 形式の印が 2 つ | 同じプラグインが 2 つの形式で入っている。明るいほうを使う。もう一方の印を押すと入れかわる。 |
| 形式の印 | プラグインの作られかたの種類（LV2 ・ VST3 ・ CLAP）。使いかたはどれも同じ。 |
| スキャン | PC の中のプラグインをさがして、棚にならべる作業。 |
| フェード | 音の出だしや終わりを、なめらかに大きく、または小さくする。 |
| バッファ | 音をまとめて処理するひとかたまりの大きさ。小さいほど遅れが減り、PC は忙しくなる。 |
| 遅れ（レイテンシ） | 弾いてから音が出るまでの時間。 |
| 遅れの補正 | 録った音を、遅れのぶんだけ前へ戻して置くこと。 |
| サンプルレート | 1 秒を何こまに分けて音を記録するか。48000 Hz がふつう。 |
| 書き出し | 曲を 1 つの音のファイルにすること。 |
