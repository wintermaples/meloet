# meloet をつかう人へ

meloet は、MIDI 鍵盤を買ったばかりの人のための DAW です。この書類は、meloet を入れて、つかって、消すまでの案内です（作る人向けの書類は、リポジトリのいちばん上の `README.md` です）。

いまの版は 0.1.0 です。Ubuntu 24.04 と 26.04 で動きます。

## 入れかた

1. GitHub の Release のページから、`meloet_0.1.0_amd64.deb` を取ります。
2. 端末をひらき、取ったファイルのある場所で、次を打ちます。

   ```bash
   sudo apt install ./meloet_0.1.0_amd64.deb
   ```

   `./` を忘れないでください。meloet が使う部品（WebKitGTK、ALSA、PipeWire など）も、いっしょに入ります。

3. アプリの一覧に「meloet」が出ます。端末から `meloet` と打っても起動します。

入る物:

| 場所 | 中身 |
|---|---|
| `/usr/bin/meloet` | meloet 本体 |
| `/usr/bin/meloet-plughost` | プラグインを動かす係（meloet が自分で起こします。じかに起動する物ではありません） |
| `/usr/share/applications/meloet.desktop` | アプリの一覧に出すための物 |
| `/usr/share/doc/meloet/` | ライセンス（`LICENSE-MIT`、`LICENSE-APACHE`）と、使っている部品の帰属表示（`NOTICE`） |

## 鍵盤のつなぎかた

1. MIDI 鍵盤を USB でつなぎます。meloet を起動する前でも、後でもかまいません。
2. 鍵盤がないあいだは、入力計に「鍵盤を USB でつなぐと、ここに出ます。つながなくても、マウスで音を書けます。」と出ます。
3. つなぐと、入力計に鍵盤の名前が出ます。はじめてのときは「音をどこから鳴らしますか」と、音の出口の一覧が出ます。↑ ↓ でえらび、Enter で決まります。行ごとのテスト音で、どこから鳴るか確かめられます。
4. えらんだ出口は覚えていて、次からは聞きません。あとから「音の設定」（Ctrl+,）で変えられます。

## 音の素材の包み

グランドピアノなど 31 の音色の音は、meloet には入っていません。はじめて起動したときに、インターネットから取りにいきます（約 240 MB）。

- 起動すると「音の素材（約 240 MB）を取りにいきます」と出ます。「取りにいく」を押すと取りはじめます。「あとで」を押すと、次の起動でまた聞きます。
- 取っている間も、鍵盤で弾けます。まだ取れていない音色は、サイン波で代わりに鳴ります。取れた音色から、本当の音で鳴りはじめます（グランドピアノがいちばん先です）。
- とちゅうでインターネットが切れても、取った所までは残ります。次は続きから取ります。
- 置き場所は `~/.local/share/meloet/sounds/` です（`XDG_DATA_HOME` を決めていれば、その下の `meloet/sounds/`）。
- 新しい包みがあるかは、1 日に 1 回まで見にいきます。見にいくのは目録のファイル 1 つだけで、名前などは送りません。
- meloet がインターネットにつなぐのは、音の素材を取るときだけです。

## プラグイン

meloet は VST3 と LV2 のプラグインを読みます。次の場所を、はじめの起動のあとにスキャンして、棚の「あとから入れたもの」にならべます。

| 形式 | 場所 |
|---|---|
| VST3 | `~/.vst3`、`/usr/lib/vst3`、`/usr/local/lib/vst3` |
| LV2 | `~/.lv2`、`/usr/lib/lv2`、`/usr/local/lib/lv2`（と `LV2_PATH` の場所） |

ほかの場所にあるときは、「音の設定 ▸ くわしい設定」の「場所を足す…」で足せます。

プラグインは meloet とは別のプロセス（`meloet-plughost`）で動きます。プラグインが止まっても、meloet と曲は無事です。

## 困ったとき

### 音が出ない

- 状態行に「出口: まだ」と出ていたら、音の出口をまだえらんでいません。「音の設定」（Ctrl+,）でえらびます。
- えらんだ出口に何もささっていないと、状態行でそう言います。ヘッドホンやスピーカーをさすか、ほかの出口をえらびます。
- PipeWire が動いているか確かめます。端末で `systemctl --user status pipewire wireplumber` と打ち、どちらも `active (running)` なら動いています。止まっていたら `sudo apt install pipewire wireplumber` で入れ、ログインしなおします。
- トラックやマスターのミュート、フェーダーの位置も見てください。

### 鍵盤が出ない

- USB のケーブルを、さしなおしてみます。
- 端末で `aconnect -l` と打ち、鍵盤の名前が出るか見ます（`aconnect` は `alsa-utils` の中にあります）。ここにも出ないときは、PC が鍵盤を見つけていません。ほかの USB の口や、ほかのケーブルを試してください。
- 鍵盤によっては、電源のスイッチや、USB MIDI のモードの切りかえがあります。鍵盤の説明書を見てください。

### 音の素材が取れない

- 「インターネットにつながっていません」と出たら、つながってから「もう一度」を押します。取った所までは残っています。
- 「ディスクがいっぱい」と出たら、`~/.local/share` のあるディスクに、言われた分の空きを作ります。
- 「こわれていた」と出たら、しばらくしてから、もう一度ためしてください。

### ようすを見る（ログ）

meloet は、困ったときのようすを端末に書きます。アプリの一覧からではなく、端末で `meloet` と打って起動すると、そこに出ます。困ったことを伝えてくれるときは、その文を写してください。

## 消しかた

```bash
sudo apt remove meloet
```

meloet の本体と `meloet-plughost` が消えます。次の物は、あなたの家のフォルダに残ります。要らなければ、手で消してください。

| 場所 | 中身 |
|---|---|
| `~/.config/meloet/` | 設定（音の出口、拡大率、足したプラグインの場所など） |
| `~/.local/share/meloet/sounds/` | 音の素材の包み（約 240 MB） |
| `~/.local/share/meloet/sf2/` | 足した SF2 の写し |
| `~/.local/state/meloet/` | なおすためのファイル（保存していない変更） |
| `~/.cache/meloet/` | プラグインのスキャンの記録、波形などの、作りなおせる物 |

作った曲（はじめは `~/ミュージック/` の下）は、あなたのファイルなので、meloet を消しても残ります。

```bash
rm -rf ~/.config/meloet ~/.local/share/meloet ~/.local/state/meloet ~/.cache/meloet
```

（`XDG_CONFIG_HOME` などを決めている人は、その下の `meloet/` です。）
