# meloet をつかう人へ

meloet は、MIDI 鍵盤を買ったばかりの人のための DAW です。この書類は、meloet を入れて、つかって、消すまでの案内です（作る人向けの書類は `docs/development/` にあります）。

いまの版は 0.5.0 です。Ubuntu 24.04 と 26.04 で動きます。

## 入れかた

1. GitHub の Release のページから、`meloet_0.5.0_amd64.deb` を取ります。
2. 端末をひらき、取ったファイルのある場所で、次を打ちます。

   ```bash
   sudo apt install ./meloet_0.5.0_amd64.deb
   ```

   `./` を忘れないでください。meloet が使う部品（WebKitGTK、ALSA、PipeWire など）も、いっしょに入ります。

3. アプリの一覧に「meloet」が出ます。端末から `meloet` と打っても起動します。

入る物:

| 場所 | 中身 |
|---|---|
| `/usr/bin/meloet` | meloet 本体 |
| `/usr/bin/meloet-plughost` | プラグインを動かす係（meloet が自分で起こします。じかに起動する物ではありません） |
| `/usr/bin/meloet-mcp` | AI のアプリと meloet をつなぐ橋（AI のアプリが起こします。じかに起動する物ではありません。「AI とつなぐ」を見てください） |
| `/usr/share/applications/meloet.desktop` | アプリの一覧に出すための物 |
| `/usr/share/doc/meloet/` | ライセンス（`LICENSE-MIT`、`LICENSE-APACHE`）と、使っている部品の帰属表示（`NOTICE`） |

## 鍵盤のつなぎかた

1. MIDI 鍵盤を USB でつなぎます。meloet を起動する前でも、後でもかまいません。
2. 鍵盤がないあいだは、入力計に「鍵盤を USB でつなぐと、ここに出ます。つながなくても、マウスで音を書けます。」と出ます。
3. つなぐと、入力計に鍵盤の名前が出ます。はじめてのときは「音をどこから鳴らしますか」と、音の出口の一覧が出ます。↑ ↓ でえらび、Enter で決まります。行ごとのテスト音で、どこから鳴るか確かめられます。
4. えらんだ出口は覚えていて、次からは聞きません。あとから「音の設定」（Ctrl+,）で変えられます。

## 音の素材の包み

グランドピアノなど 31 の音色の音は、meloet には入っていません。はじめて起動したときに、インターネットから取りにいきます（約 240 MB）。

- 起動すると「音の素材（約 240 MB）を取りにいきます」と出ます。「取りにいく」を押すと取りはじめます。「あとで」を押すと、次の起動でまた聞きます。
- 取っている間も、鍵盤で弾けます。まだ取れていない音色は、サイン波で代わりに鳴ります。取れた音色から、本当の音で鳴りはじめます（グランドピアノがいちばん先です）。
- とちゅうでインターネットが切れても、取った所までは残ります。次は続きから取ります。
- 置き場所は `~/.local/share/meloet/sounds/` です（`XDG_DATA_HOME` を決めていれば、その下の `meloet/sounds/`）。
- 新しい包みがあるかは、1 日に 1 回まで見にいきます。見にいくのは目録のファイル 1 つだけで、名前などは送りません。
- meloet がインターネットにつなぐのは、音の素材を取るときと、新しい版が出ているかを見るとき（下の「新しい版のお知らせ」）だけです。

## プラグイン

meloet は VST3 と LV2 のプラグインを読みます。次の場所を、はじめの起動のあとにスキャンして、棚の「あとから入れたもの」にならべます。

| 形式 | 場所 |
|---|---|
| VST3 | `~/.vst3`、`/usr/lib/vst3`、`/usr/local/lib/vst3` |
| LV2 | `~/.lv2`、`/usr/lib/lv2`、`/usr/local/lib/lv2`（と `LV2_PATH` の場所） |

ほかの場所にあるときは、「音の設定 ▸ くわしい設定」の「場所を足す…」で足せます。

プラグインは meloet とは別のプロセス（`meloet-plughost`）で動きます。プラグインが止まっても、meloet と曲は無事です。

## できること（0.3.0 のあとに増えたもの）

キーを忘れたら、メニュー「ヘルプ」▸「キーの一覧」。上の箱に「ループ」や「Ctrl」と打つと絞りこめます。Esc で閉じます。「ヘルプ ▸ 使い方をひらく」で、この案内をブラウザでひらきます。

### 弾く ・ 録る

- さっきのを残す（Shift R）：録音を押していなくても、直前に弾いたものをクリップにできます。再生に合わせて弾いた分は聞こえていた位置に、止めたまま弾いた分は再生線のある小節の頭から入ります。
- キーで弾く（Ctrl K）：MIDI 鍵盤がなくても、パソコンの文字のキーで弾いて録れます。A S D F G H J K L ; が白鍵、W E T Y U O P が黒鍵、Z ／ X でオクターブを上下します。オンのあいだ 1 文字のショートカットは止まります。Esc でやめます。日本語入力がオンだと鳴りません。
- アルペジオ：トラックの「アルペジオ」をオンにして和音を押さえると、曲のテンポに合ったフレーズになります（上へ／下へ／上下／ばらばら、1/4〜1/32 と三連符、1〜3 オクターブ、指を離しても続ける）。鍵を1つだけ押さえると連打になります。録音には、鳴ったノートがそのまま入ります。曲の中のノートにはかかりません。
- メトロノームの設定（メトロノームの ▾）：音量、3 つの音（ピッ、カチ、カウベル）、録音のときだけ鳴らす、手拍子でテンポを決める（タップ）。

### ピアノロール

- スケール固定をオンにすると、スケールの音の行が明るく見え、その音だけに書きこめます（メジャー、マイナー、ハーモニックマイナー、メロディックマイナー、メジャーペンタトニック、マイナーペンタトニック、ブルース、ドリアン、ミクソリディアンの9種類）。
- コード進行の型（王道・カノン・小室・循環・ポップ・切ない）を聞いて、1 小節に 1 つずつ並べられます（スケール固定のとき）。
- 選んだノートのベロシティを割合で変える・だんだん変える・ばらつかせる。「次の音までのばす」で音を次の音までつなげます。
- ほかのトラックのノートを薄く重ねて見られます（「ほかのトラックも見る」）。ほかのパートに合わせて書くときに使います。▾ で見せるトラックを選べます。
- 再生中、再生線が通っているノートがトラックの色で光ります（「表示 ▸ 鳴っている音を光らせる」で切りかえ。はじめはオン）。

### アレンジ

- クリップをくり返す：クリップの名前の右端の持ち手を右へ引くか、「くり返す…」（Ctrl R）で回数を打ちます。写しはすぐ後ろに続き、1 回で取り消せます。いくつか選んでいれば、ひとかたまりでくり返します。
- 区間ごと動かす：マーカーを右クリックして、その区間（次のマーカーまで）をすぐ後ろに複製したり、消して詰めたり、前に空きの小節を入れたりできます。クリップ、オートメーション、テンポ、拍子、マーカーがまとめて動き、1 回で取り消せます。区間の両端が小節の頭のときに使えます。
- トラックの複製（トラックの頭を右クリック ▸ 「トラックを複製」）：音源、エフェクト、ミキサーの設定、クリップ、オートメーションごと、すぐ下に写します。プラグインは、いま鳴っている状態から始まります。
- キーのトラックやクリップを音のクリップにする（右クリックから）。音源とエフェクトを通した音が、すぐ下の新しい歌（音）のトラックに置かれ、元のトラックはミュートされます。取り消せます。
- ドラムのパターン集：棚の「パターン」に 1 小節のドラムの型が 12 個（8 ビート、16 ビート、4 つ打ち、シャッフル、フィルイン…）。▶ で聞いて、Enter で再生線の小節に置けます。続けて Enter で次の小節に並びます。

### 歌のクリップ

- 歌のいいとこ取り：何回か録った歌のテイクから、いいところだけをつないで1本にできます。歌のクリップを右クリックして「いいとこ取り」をえらぶと、トラックの下にテイクが並びます。使いたいテイクの上を横に引くと、その範囲はそのテイクが鳴ります。つなぎ目は自動でなめらかになります。「もとに戻す」で、いつでも1本のテイクに戻せます。
- 歌の音程を寄せる：歌のクリップの音の高さを、スケールの音へ寄せます（強さ 0〜100 %）。ひとりの声や、音が1つずつの楽器に使えます。右のパネル「選んだクリップ」の「音程を寄せる」で強さを決めます。寄せる先は、強さを 0 から上げたときの曲のスケールです。あとで変えたいときは「いまのスケールにする」を押します。
- 音のクリップを逆にする・ノーマライズ（いちばん大きい音を −1.0 dB にそろえる）。クリップの右クリックから。どちらも取り消せます。

### 音色とミキサー

- 最初から入っている音には、パラメータのパネルに4つのつまみがあります：「明るさ」「立ち上がり」「のび」「ゆれ」（ドラムのキットは「明るさ」と「のび」だけ）。ほかのパラメータと同じように、オートメーションで動かせます。
- 内蔵エフェクトが9つになりました：ゲート（音のあいだの雑音を消す）、ディエッサー（歌のサ行のきつさをやわらげる）、サチュレーション（あたたかさや荒さを足す）を足しました。
- 内蔵エフェクトのプリセット：はじめから入っている設定（コンプレッサーの「歌をそろえる」など）を選べます。いまの設定に名前をつけて、この PC に残すこともできます。
- マスターの音量のオートメーションとフェードアウト：メニュー「編集」の「曲の終わりにフェードアウトをつける…」で長さ（小節）を打つと、曲の終わりに向かってマスターの音量が下がります。線はほかのオートメーションと同じように直せて、書き出したファイルにもそのまま入ります。
- ミキサーのマスターの右に「仕上げのメーター」：いまの大きさ（直近 3 秒）と曲ぜんたいの大きさ（LUFS）、トゥルーピーク（dBTP）、マスターの音の 24 本の棒、左右をまぜて聞く「モノで聞く」（聞くだけのもので、書き出しは変わりません）。
- 音が大きすぎるときのお知らせ（マスターのリミッターがずっとおさえている、またはマスターが 0 dB を越えた）と、全部のトラックを一度に下げるボタン。
- 音に合わせて動く絵：上の帯の「マスター」の左に、マスターの音を低い音から高い音まで 24 本の棒で（「表示 ▸ 音の動きを見せる」で消せます）。

### 書き出し

- mp3 のファイルにも書き出せます。「くわしく」で「ビットレート」を 128 / 192 / 256 / 320 kbps からえらびます（はじめは 192）。サンプルレートは 44100 Hz か 48000 Hz です。
- 書き出しで「公開先に合わせる」をえらぶと、曲ぜんたいの大きさを −14 LUFS に合わせます（トゥルーピークは −1 dBTP まで）。書き出す前のたしかめに、曲ぜんたいの大きさ（LUFS）とトゥルーピーク（dBTP）が出ます。
- 書き出しの「くわしく」で、曲の情報（題名・作者・絵）をファイルに入れられます（絵は flac と mp3 のとき。png か jpg、5 MB まで）。作者は覚えておきます。
- 書き出しが終わると「書き出しました」が出て、波の形と大きさ（LUFS とトゥルーピーク）が見られます。「PC のプレーヤーで聞く」でその場で聞けます。

### ファイル

- ファイル ▸ 最近ひらいた曲：最近の 10 曲から選んでひらけます（場所もうすく出ます）。「一覧を消す」で空にできます。

### ことば

- 表示 ▸ ことば / Language で、画面を英語（English）にできます。はじめは PC のことばに合わせます。切りかえると画面を読み込みなおします（曲と音はそのまま）。新しい曲やトラックの名前は、作ったときのことばになります（もうある名前は変わりません）。「使い方をひらく」は、英語のときは英語の案内をひらきます。

### 新しい版のお知らせ

- 新しい版が出ると、止まっているときにステータスラインでお知らせします（1日に1回まで。送るのは meloet の版だけ。音の設定の「新しい版をたしかめる」で切れます）。入れるのは手で行います（deb を落として入れます）。

### 増えたキー

| キー | すること |
|---|---|
| Shift R | さっきのを残す |
| Ctrl K | キーで弾く（オン ・ オフ） |
| Ctrl R | クリップをくり返す（回数の箱） |

## AI とつなぐ

AI のアプリ（Claude Code や Claude Desktop など、MCP という約束で話せる物）から、動いている meloet を使えるようにできます。AI にできること:

- 曲を読んで、助言する。
- 頼まれたら、曲に書く（ノート、ミキサー、エフェクト、音色、オートメーション、トラックやクリップ、保存 ・ ひらく ・ 書き出し）。書いた物は 1 手ずつ取り消せます。いくつもの変更を、まとめて 1 手にすることもできます。
- MIDI ファイル（.mid）を曲に読みこむ。曲のノートを MIDI ファイルに書き出す。
- プラグインのプリセットを選ぶ ・ 保存する。プラグインの設定をまるごと読んで、もとに戻す。Surge XT では、パッチの中身（LFO でビブラートをかけるなど、モジュレーションの割り当て）も変えられます。
- ドラムのトラックで、どの鍵盤がどの太鼓かを調べる。
- ミュートの組み合わせに名前をつけて曲に残し、あとで呼び出す。
- この PC にある曲のファイルを探す（最近ひらいた曲、曲のフォルダ）。
- 書き出した音を調べて、音の大きさなどを数で伝える。高い音 ・ 低い音のどのあたりが鳴っているか、2 つのトラックが同じ高さでぶつかっていないかも調べます。音色を知るために、1 つの音だけを書き出すこともできます。

### オンにする

「音の設定 ▸ くわしい設定 ▸ AI とつなぐ」をオンにします。はじめはオフです。

- オンの間だけ、この PC の中に、AI のアプリがつなぐ口をひらきます。同じユーザーで動いているアプリだけがつなげます。ほかの人や、インターネットからはつなげません。
- 右に、いまの口のようすが出ます。「閉じています」（オフ）、「待っています」（オンで、AI はまだつないでいない）、「つながっています」。
- オフにすると口を閉じ、つながっていた AI も切れます。
- オン ・ オフは meloet が覚えています（曲には入りません）。
- AI のために書き出した音のファイルは、同じユーザーだけが読める一時フォルダ（`/tmp/meloet-ai-<ユーザーの番号>`）に置かれ、1 時間たつか、「AI とつなぐ」をオフにするか、meloet を終えると消えます。AI（Claude）は音を耳で聞くのではなく、AI のアプリが自分のプログラムでそのファイルを読みます。
- 保存していない変更があるときは、AI は曲をひらいたり新しい曲にしたりしません。
- AI のアプリは、読んだ曲の中身（ノートやテンポなど）を、そのアプリの会社のサーバーに送ることがあります。何が送られ、どう使われるかは、そのアプリの決まりを見てください。

### AI のアプリに登録する

AI のアプリが `/usr/bin/meloet-mcp` を起こし、それが meloet の口につなぎます。AI のアプリを先に起動してもかまいません。meloet で「AI とつなぐ」をオンにすると、次に AI に頼んだときに、ひとりでにつながります。録音中と書き出し中は、AI は曲を変えられません。

Claude Code では、端末で次を 1 回打ちます。

```bash
claude mcp add --transport stdio --scope user meloet -- /usr/bin/meloet-mcp
```

Claude Desktop（Linux 版はベータです）では、設定のファイル `~/.config/Claude/claude_desktop_config.json` に、次のように書きます。ほかの物がもう書いてあるときは、`mcpServers` の中に `meloet` の行を足します。書いたら Claude Desktop を起動しなおします。

```json
{"mcpServers": {"meloet": {"command": "/usr/bin/meloet-mcp"}}}
```

設定のファイルの場所と書きかたは、AI のアプリの版によって変わることがあります。

### AI が書いた物を戻す

AI が曲に書いた物は、ふつうの操作と同じように、取り消しの履歴に 1 手ずつ出ます。気に入らなければ、「取り消す」（Ctrl+Z）や「取り消しの履歴」の帯（H）で戻せます。AI がまとめて変えた物は 1 手なので、1 回で戻ります。

AI がまとめて変えている間（ふつうは一瞬です）、あなたの操作は少し待ってから行われます。鍵盤の音はいつもどおり鳴ります。

## 困ったとき

### 音が出ない

- 状態行に「出口: まだ」と出ていたら、音の出口をまだえらんでいません。「音の設定」（Ctrl+,）でえらびます。
- えらんだ出口に何もささっていないと、状態行でそう言います。ヘッドホンやスピーカーをさすか、ほかの出口をえらびます。
- PipeWire が動いているか確かめます。端末で `systemctl --user status pipewire wireplumber` と打ち、どちらも `active (running)` なら動いています。止まっていたら `sudo apt install pipewire wireplumber` で入れ、ログインしなおします。
- トラックやマスターのミュート、フェーダーの位置も見てください。

### 鍵盤が出ない

- USB のケーブルを、さしなおしてみます。
- 端末で `aconnect -l` と打ち、鍵盤の名前が出るか見ます（`aconnect` は `alsa-utils` の中にあります）。ここにも出ないときは、PC が鍵盤を見つけていません。ほかの USB の口や、ほかのケーブルを試してください。
- 鍵盤によっては、電源のスイッチや、USB MIDI のモードの切りかえがあります。鍵盤の説明書を見てください。

### 音の素材が取れない

- 「インターネットにつながっていません」と出たら、つながってから「もう一度」を押します。取った所までは残っています。
- 「ディスクがいっぱい」と出たら、`~/.local/share` のあるディスクに、言われた分の空きを作ります。
- 「こわれていた」と出たら、しばらくしてから、もう一度ためしてください。

### ようすを見る（ログ）

meloet は、困ったときのようすを端末に書きます。アプリの一覧からではなく、端末で `meloet` と打って起動すると、そこに出ます。困ったことを伝えてくれるときは、その文を写してください。

## 消しかた

```bash
sudo apt remove meloet
```

meloet の本体と `meloet-plughost` が消えます。次の物は、あなたの家のフォルダに残ります。要らなければ、手で消してください。

| 場所 | 中身 |
|---|---|
| `~/.config/meloet/` | 設定（音の出口、拡大率、足したプラグインの場所など）、自分で残したエフェクトのプリセット、新しい版を最後に見た日 |
| `~/.local/share/meloet/sounds/` | 音の素材の包み（約 240 MB） |
| `~/.local/share/meloet/sf2/` | 足した SF2 の写し |
| `~/.local/state/meloet/` | なおすためのファイル（保存していない変更） |
| `~/.cache/meloet/` | プラグインのスキャンの記録、波形などの、作りなおせる物 |

作った曲（はじめは `~/ミュージック/` の下）は、あなたのファイルなので、meloet を消しても残ります。

```bash
rm -rf ~/.config/meloet ~/.local/share/meloet ~/.local/state/meloet ~/.cache/meloet
```

（`XDG_CONFIG_HOME` などを決めている人は、その下の `meloet/` です。）
